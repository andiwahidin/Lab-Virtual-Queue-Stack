# Laboratorium Virtual Informatika: Struktur Data Stack & Queue (Kelas X)

Aplikasi web Laboratorium Virtual (Lab Maya) interaktif untuk mata pelajaran **Informatika Kelas X (Fase E)** pada materi **Memilih Struktur Data untuk Masalah di Kehidupan Nyata: Tumpukan (Stack / LIFO) dan Antrean (Queue / FIFO)**.

## ✨ Fitur Utama
1. **Splash Screen & Loading Interaktif**: Ilustrasi perbandingan visual *Stack (Push/Pop)* dan *Queue (Enqueue/Dequeue)* beserta indikator inisialisasi memori.
2. **Materi & Studi Kasus Visual**: Membahas studi kasus tumpukan formulir pasien di loket rumah sakit, tumpukan piring, serta analisis *Higher Order Thinking Skills (HOTS)*.
3. **Meja Kerja Simulasi 4 Misi**:
   - **Misi 1**: Studi kasus antrean loket rumah sakit yang keliru menggunakan *Stack (LIFO)*.
   - **Misi 2**: Solusi antrean loket rumah sakit yang adil menggunakan *Queue (FIFO)*.
   - **Misi 3**: Simulasi tumpukan piring bersih (*Stack / LIFO*).
   - **Misi 4**: Eksperimen bebas & pengujian operasi *Peek / Front*.
4. **Tabel Data Percobaan Otomatis**: Mencatat urutan data masuk (*Input*), urutan data keluar (*Output*), dan verifikasi ketuntasan misi.
5. **LKPD Digital 10 Soal + Ekspor PDF A4**: Dilengkapi pengecekan jawaban otomatis pada Bagian B dan unduh laporan PDF instan menggunakan `jsPDF 2.5.1`.
6. **Web Audio API Synthesizer**: Efek suara (SFX) dan musik latar ambient (BGM) murni tanpa ketergantungan berkas MP3 eksternal.

## 🚀 Cara Menjalankan & Publikasi
- Letakkan `index.html`, `style.css`, dan `script.js` di dalam satu folder yang sama.
- Buka `index.html` menggunakan browser modern, atau unggah langsung ke **GitHub Pages** / **Netlify**.
